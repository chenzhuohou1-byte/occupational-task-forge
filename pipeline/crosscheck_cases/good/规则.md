# 差旅住宿报销核算规则（合成玩具案例，纯虚构、可公开；仅供 crosscheck 自测）

> 两份材料 + 一处跨材料 join：报销明细逐行 → 按城市查《城市住宿标准表》封顶。

## 材料
- `城市标准`：字典 `{城市: 每日住宿封顶(元)}`。
- `明细`：列表，每行 `{行号, 城市, 住宿单价(元/日), 天数}`；`行号`为唯一行键。

## 逐行口径
- 若该行 `城市` **不在** `城市标准` 里 → 判「城市未备案」：该行 `可报 = 0.00`，`行号` 计入 `异常行清单`，且**不**计入超标。
- 否则：`日可报 = min(住宿单价, 该城市每日封顶)`；`可报 = round(日可报 × 天数, 2)`。
  - 若 `住宿单价 > 该城市每日封顶`（**严格大于**；相等不算）→ `行号` 计入 `超标行清单`。

## 汇总
- `可报总额 = round(所有行可报之和, 2)`。
- `超标行清单` / `异常行清单`：行号升序数组（集合语义，顺序不计分）。

## 输出
```
{
  "明细结果": [{"行号": n, "可报": x.xx}, ...]   // 按行号升序
  "汇总": {"可报总额": X.XX, "超标行清单": [...], "异常行清单": [...]}
}
```
